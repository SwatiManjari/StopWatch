# Stopwatch

A simple and responsive stopwatch built using HTML, CSS, and JavaScript.

## Features

- Start the stopwatch
- Stop the stopwatch
- Reset the stopwatch
- Displays hours, minutes, seconds, and milliseconds
- Continues from the previous time after stopping
- Responsive design for different screen sizes

## Technologies Used

- HTML
- CSS
- JavaScript

## How It Works

The stopwatch uses JavaScript's `Date.now()` to calculate the elapsed time and `setInterval()` to update the display every 10 milliseconds.
